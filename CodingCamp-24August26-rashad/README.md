# CodingCamp To-Do List Life Dashboard

## Required files
- index.html
- css/style.css
- js/script.js

## Implemented MVP
- Current time and date
- Time-based greeting
- 25-minute focus timer
- Start, Stop, Reset
- Add/Edit/Complete/Delete tasks
- Task persistence with Local Storage
- Quick links with Local Storage
- Responsive layout

## 3 Challenges implemented
1. Light / Dark mode
2. Custom name in greeting
3. Prevent duplicate tasks

## Additional
- Pomodoro duration can also be changed.
- Keep the `.kiro` folder generated/used by Kiro in the GitHub repository as required by the course.
